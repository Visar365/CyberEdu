# Wireframe dhe prototipi UI/UX — CyberEdu

Ky dokument përshkruan prototipin interaktiv që dorëzohet në `Platforme_Siguria_Kibernetike_AI/index.html`. Figma nuk është e nevojshme për ta provuar: ekrani është implementuar në HTML/CSS dhe navigimi funksionon lokalisht.

## Rrjedha kryesore

```text
Hyrje / Krijo profil
        ↓
Kryefaqja ──→ Mësimet ──→ Detaji i mësimit ──→ Shëno përfundimin
    ├────────→ Kuizet ──→ Rezultati
    ├────────→ Mentorja
    └────────→ Këshilla sigurie
```

## Ekranet

| Ekrani | Përmbajtja dhe veprimi kryesor |
|---|---|
| Hyrja | Krijim profili ose hyrje lokale; shpjegon se ruajtja është vetëm në shfletues. |
| Kryefaqja | Përshëndetje, progresi, pikët, niveli, mësimet e rekomanduara dhe këshilla ditore. |
| Mësimet | Lista e pesë temave; hap detajet dhe shënon mësimin si të përfunduar. |
| Kuizet | Pesë pyetje me alternativa, shpjegim pas përgjigjes dhe rezultat përfundimtar. |
| Mentorja | Pyetje të lira me përgjigje edukative të paracaktuara; sugjerime për tema. |
| Këshilla sigurie | Kartela për fjalëkalime, phishing, MFA, përditësime, privatësi dhe kopje rezervë. |

## Parime vizuale dhe ndërveprimi

- Ndërfaqe shqipe, me etiketa të shkurtra dhe hapa të kuptueshëm për fillestarë.
- Navigim anësor në desktop dhe paraqitje responsive për ekrane më të vogla.
- Ngjyra të qeta, hapësirë e bollshme, kartela të ndara qartë dhe fokus i dukshëm për tastierë.
- Progresi paraqitet si numra dhe shirit progresi; veprimet japin reagim të menjëhershëm.

## Si ta shohësh

Hap `Platforme_Siguria_Kibernetike_AI/index.html` në shfletues ose nis konfigurimin Chrome nga Run and Debug në VS Code. Krijo një profil demonstrues për të parë gjendjen e autentikuar.
